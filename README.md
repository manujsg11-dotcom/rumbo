# Rumbo

Plan de estudio para Bachillerato: exámenes, notas, horario, plan diario y calculadora de la PAU.

Ábrela en https://manujsg11-dotcom.github.io/rumbo/ y, en el iPhone, *Compartir → Añadir a pantalla de inicio*.
Los datos se guardan solo en tu dispositivo. Para llevarlos a otro: *Perfil → Ajustes → Pasar mis datos a otro dispositivo*.
